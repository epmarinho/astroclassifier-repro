# AstroClassifier paper

The journal-targeted manuscript is **cnn_transformer_article_ascom.tex**, formatted
with Elsevier's **elsarticle** class for *Astronomy and Computing*. The manuscript
contains the completed one-pass object-independent test and its aggregate statistical
analysis. Build it with **make** or **make ascom**.

The build is pinned to the official **elsarticle 3.5 (2026-01-09)** support files
under **elsevier/elsarticle-3.5**. The shared **.latexmkrc** makes command-line
latexmk and VS Code LaTeX Workshop use that vendored class and allows the extra
passes needed to stabilize references. Their CTAN source and SHA-256 are recorded in that
directory's **SOURCE.md**. The archive produced by **make zip** includes the class,
bibliography style, manuscript source, compiled PDF, and scientific figures.

The scientific figures are generated by **make_ascom_results_figures.py** from the
frozen membership and tensor inventories, the sealed prediction manifest, and the
aggregate scoring outputs. Before writing any figure, the script checks the pinned
SHA-256 values of all five source artifacts and checks the individual tensor and
prediction-record hashes used by the plots. The representation panel selects one
validation object per class by distance to the class-median source FOV (object ID
breaks ties); the confusion matrices average the three frozen representation-A
fits per family. Run the script from the project root with the AstroClassifier
Python environment when the figures need to be reproduced.

The earlier Springer-layout draft remains preserved locally as
**cnn_transformer_article_snjnl.tex** and is intentionally excluded from the
Astronomy and Computing submission archive.
